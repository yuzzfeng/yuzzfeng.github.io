Software & Data

Software and datasets for geospatial visualisation and cartographic generalisation.

Basemap3D

Create interactive 3D city maps with a few lines of Python. Combine city meshes, buildings, terrain, imagery, trees and your own geospatial data, then display the map in Jupyter or Colab or export it as HTML.

Explore interactive examples →  ·  GitHub repository

MapGen — Building generalisation data

Raster and vector datasets for learning cartographic building generalisation, accompanying “Learning cartographic building generalization with deep convolutional neural networks” (Feng, Thiemann & Sester, 2019).

The repository provides dataset links, access instructions and the recommended citation.
